## Slides = Markdown
//@ [] 00:45

Une présentation SliDesk, c'est un simple fichier [Markdown](https://fr.wikipedia.org/wiki/Markdown)

```markdown
## Bonjour 👋

Chaque `##` commence une nouvelle slide.

/*
Des notes pour la vue présentateur.
*/
```

/*
Tout ce qui s'affiche à l'écran est écrit en Markdown : c'est le fichier qui fait la présentation.

Un titre de niveau 2 ouvre une nouvelle slide. Les notes du présentateur s'écrivent dans un bloc de commentaires en bas de la slide : elles n'apparaissent que dans la vue présentateur, jamais pour le public.

À chaque enregistrement, le navigateur se recharge tout seul : on écrit, on voit immédiatement le résultat.
*/
